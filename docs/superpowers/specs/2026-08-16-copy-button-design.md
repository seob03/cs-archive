# Code Copy Button Design

## Goal

코드 블록의 복사 버튼을 항상 명확하게 보여주고, 버튼과 아이콘의 규격 및 정렬을 바로잡는다.

## Design

- `.clipboard-button`은 hover 여부와 관계없이 항상 보이도록 `opacity: 1`을 적용한다.
- Quartz 기본 외부 여백이 위치 계산을 흐리지 않도록 `margin: 0`을 적용한다.
- 버튼은 코드 헤더 높이에 맞춘 `2rem × 2rem` 정사각형으로 고정한다.
- SVG 아이콘은 `1rem × 1rem`으로 고정하고 grid 중앙 정렬을 유지한다.
- 버튼은 코드 블록 오른쪽 위에 배치하며 언어 헤더 안에서 시각적으로 중앙에 오도록 위치를 조정한다.
- 기본 상태에서는 어두운 배경과 은은한 테두리를 사용한다.
- hover 및 키보드 focus 시 보라색 테두리와 조금 밝은 배경을 적용한다.
- 클릭 후 기존 체크 아이콘으로 잠시 바뀌는 Quartz 동작은 유지한다.
- 라이트 모드와 다크 모드에서 코드 블록 자체는 동일한 어두운 배경을 사용하므로 버튼도 동일한 규격과 색을 사용한다.

## Verification

- 스타일 회귀 테스트로 항상 표시되는 투명도, 외부 여백, 버튼 크기, 아이콘 크기와 hover 배경을 검증한다.
- 전체 테스트, 타입 검사, 포맷 검사와 Quartz 빌드를 실행한다.
